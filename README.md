# bilibili-userscripts

个人自用的B站用户脚本集合

## 脚本列表

| 脚本 | 简介 | 安装 |
|---|---|---|
| [B站未开播直播间显示大航海榜](scripts/bilibili-offline-guard-rank/) | 没开播或轮播中的直播间也能看大航海榜（周榜/月榜/陪伴榜），活动页同样适用 | [Greasy Fork](https://greasyfork.org/scripts/599644) · [GitHub 直装](https://raw.githubusercontent.com/PolarBears/bilibili-userscripts/main/scripts/bilibili-offline-guard-rank/bilibili-offline-guard-rank.user.js) |

安装前需在浏览器安装用户脚本管理器，如 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)，点击安装链接后按管理器提示确认即可。

B站更新可能导致脚本失效，遇到问题请到 [Issues](https://github.com/PolarBears/bilibili-userscripts/issues) 反馈。
