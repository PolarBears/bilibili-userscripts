# B站未开播直播间显示大航海榜

让未开播的B站直播间也能查看官方"大航海"榜单，即大家常说的舰长榜 / 舰队列表（周榜 / 月榜 / 陪伴榜）。没开播、下播、停播、轮播中的直播间都适用，活动页同样生效。界面为B站官方原生组件，与真实开播的直播间完全一致——脚本不自己绘制任何界面，B站前端改版后样式自动跟随。

## 使用须知

- 页面整体会呈现开播状态的界面（如头部徽章、热门榜入口）
- 播放器区域仍为B站官方占位页；主播真实开播后自动恢复正常直播画面，排行榜随官方消息无缝切换为实时数据
- 轮播中的直播间同样生效，轮播画面保持播放不受影响
- 仅修改页面内存中的数据：不发送任何额外请求，不与服务器交互，不影响账号
- 控制台中带 `[大航海榜]` 前缀的日志可判断脚本状态（info = 生效，warn = 异常），反馈问题时可一并附上
- 关闭/停用脚本后刷新页面即完全还原
